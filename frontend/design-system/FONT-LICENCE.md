# Police de marque — Kaushan Script

Le nom « Tratra » est composé en **Kaushan Script** (script de marque ; aucun autre texte ne l'utilise).

- Auteurs : Pablo Impallari, Igino Marini (2011).
- Licence : **SIL Open Font License 1.1** — usage commercial, intégration dans un site ou une application,
  redistribution avec le logiciel : autorisés. Texte complet : `frontend/public/fonts/OFL-KaushanScript.txt`
  (copie dans `flutter_tratra/assets/fonts/`).
- Fichier : `KaushanScript-Regular.ttf`, **non modifié** (le nom réservé « Kaushan Script » interdit de
  redistribuer une version modifiée sous ce nom). Ne pas sous-ensembler ni renommer la police.
- Source : dépôt officiel Google Fonts (`ofl/kaushanscript`).

Les autres polices (Montserrat, Poppins) sont également sous SIL OFL 1.1.
L'ancienne police Bonskin (licence « usage personnel ») a été retirée du projet.
